# Aprendendo Java

Primeiro exercício de saída no terminal com Java.

**Projeto desenvolvido para fins educacionais.** O arquivo <code>src/OlaMundo.java</code> contém uma classe com método <code>main</code> que imprime uma mensagem. É um ponto de partida para praticar compilação e execução de um programa Java.

## Como executar

Instale um JDK e, a partir da raiz do repositório, execute:

~~~bash
git clone https://github.com/Rafael-M-Silva/aprendendo-java.git
cd aprendendo-java
javac src/OlaMundo.java
java -cp src OlaMundo
~~~

O repositório também contém arquivos gerados por uma IDE; eles não são necessários para o comando acima.
